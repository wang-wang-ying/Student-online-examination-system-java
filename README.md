# 学生在线考试系统-java
### 1、系统功能
在线考试管理系统，采用前后端分离架构。后端基于Spring Boot + MyBatis-Plus，前端基于Vue3 + Element Plus，实现从题库管理、考试组织、在线答题到 成绩分析的全流程闭环！

· 登录

· 首页

· 考试中心：我的考试 | 在线答题（倒计时、答题卡、自动交卷） | 我的成绩

· 成绩管理：成绩明细（人工阅卷） | 成绩统计（概览卡片、及格率分析）

· 考试管理：试卷管理（组卷、发布） | 考试安排（发布、参考范围设置）

· 题库管理：科目管理 | 题目管理（单选、多选、判断、简答）

· 学生管理：学生列表

· 系统管理：菜单管理 | 角色管理 | 账号管理
